## Repository Overview

An API-based image viewer web application that allows users to verify C2PA content credentials as well as view EXIF and IPTC information embedded within the image.

Features include C2PA verification with provenance history, metadata extraction for camera and exposure settings, and digital source type detection for AI-generated content.
