## Repository Overview

traffiCOracle is a free, live traffic dashboard for Bangalore. It shows you how fast (or slow) the city is moving right now — and how today's conditions compare to the last few months.

No app to install, no login, and no server running behind it. Open it in any browser and it works immediately. All the number-crunching happens inside your browser.
