## Repository Overview

Markdown is one of the greatest cross-platform information formats ever invented. Ironically, while it is easy to read, it is also somehow difficult to read.

FlatWrite makes it easy — and actually pleasant — to work with markdown files. It renders your markdown in the most pleasing, customisable viewing format. Export it as HTML or PDF, or send it around as a shareable URL.

> Write once, style many worlds.
